# Cadastro acadêmico — TypeScript

Projeto-base modular migrado para TypeScript em modo estrito.

## Instalação

```bash
npm install
```

## Verificar os tipos

```bash
npm run check
```

## Compilar e executar

```bash
npm run build
npm start
```

Os imports locais usam extensão `.js` porque o projeto utiliza `NodeNext` com módulos ESM.
